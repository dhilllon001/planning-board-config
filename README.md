# Planning Board · Auto Accept Config

Team-specific configuration UI for Planning Board auto-accept rules.

## Fields

- Auto Accept master toggle
- Per leg type (Pickup / Delivery / Movement): enable, lead time, time of day, days allowed, regions
- Customer include / exclude
- Live rule summary

## Develop

```bash
npm install
npm run dev
```
